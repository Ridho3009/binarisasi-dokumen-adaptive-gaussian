# Folder Citra Contoh

Folder ini dibaca secara otomatis oleh aplikasi Flask.

## Cara Menambah atau Mengganti Citra

1. Taruh berkas gambar (PNG, JPG, JPEG, atau BMP) ke dalam folder ini.
2. **Muat ulang halaman** pada browser — citra baru akan langsung muncul dalam daftar
   tanpa mengubah kode.
3. Klik nama citra baru di daftar untuk mulai memproses.

## Citra yang Tersedia

- `dokumen_merata.jpg`: cahaya merata (pembanding)
- `dokumen_berbayangan.jpg`: bayangan garis-garis (kasus utama)
- `dokumen_kuning_bernoda.jpg`: kertas menguning dengan noda

Ketiganya telah diperkecil (sisi terpanjang 1200 piksel) agar ringan.
